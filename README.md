# Contact Book

A modern, mobile-first Progressive Web App (PWA) that replicates the look and feel of a native phone contact book. Built as a single-file HTML application with no external dependencies.

---

## Overview

Contact Book is a lightweight, self-contained web application that allows users to store, view, search, edit, and delete personal contacts directly from their browser. It is designed to mimic the native contact experience found on modern smartphones, using smooth transitions, alphabetical grouping, and a clean interface built entirely with vanilla HTML, CSS, and JavaScript.

All data is stored locally in the browser using `localStorage`, meaning no server, database, or account is required.

---

## Features

- **Add Contacts** -- Create new entries with first name, last name, phone number, email, and company.
- **View All Contacts** -- Browse an alphabetically sorted, grouped list with colored initial avatars.
- **Search** -- Real-time filtering by name or company as you type.
- **Contact Detail View** -- Tap any contact to see full details with native call and email actions.
- **Edit Contacts** -- Modify any existing contact's information.
- **Delete Contacts** -- Remove contacts with a confirmation dialog to prevent accidental deletion.
- **Persistent Storage** -- All data survives page reloads and browser restarts via `localStorage`.
- **PWA-Ready** -- Can be installed to the home screen on iOS and Android for a full-screen app experience.
- **Zero Dependencies** -- No frameworks, no build step, no CDN links. One file, fully self-contained.
- **Safe Area Support** -- Respects notches and home indicators on modern devices.
